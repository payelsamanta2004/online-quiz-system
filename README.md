# online-quiz-system

Project Overview

An interactive Online Quiz System developed using Python and MySQL. The system provides user registration, login, quiz participation, admin question management, timer functionality, score calculation, and result generation.

Features

- User registration and login
- Admin login and management panel
- Add, view and update quiz questions
- Multiple-choice questions
- Timed quiz
- Automatic score calculation
- Quiz result management
- PDF result generation
- MySQL database integration

Technologies Used

- Python
- Tkinter
- MySQL
- ReportLab

Project Workflow

1. User registers or logs in
2. User starts the quiz
3. Multiple-choice questions are displayed
4. Timer tracks the quiz duration
5. User submits answers
6. Score is calculated automatically
7. Quiz result is generated

How to Run

Install the required packages:

pip install -r requirements.txt

Configure the MySQL database and update the database connection details in the project.

Run the application:

python main.py

Project Output

The system provides an interactive quiz interface with timed questions, automatic scoring and result generation.
